# UI DESIGN RULES (MANDATORY)

These rules apply to ALL frontend, dashboard, analytics, trading, paper trading, market intelligence, and AI-related interfaces.

## Product Identity

Quant Decision Engine is a:

* Professional Market Intelligence Platform
* AI-Assisted Trading Workstation
* Quantitative Analysis Terminal

It is NOT:

* A gaming UI
* A crypto meme dashboard
* A cyberpunk toy project
* A neon showcase

## DESIGN STYLE

Primary Inspirations:

1. Bloomberg Terminal
2. TradingView
3. Modern AI Command Center

Design Characteristics:

* Dark theme first
* Professional appearance
* High information density
* Clean hierarchy
* Desktop-first experience
* Mobile-responsive layouts
* Fast readability

## TECHNOLOGY STACK

Preferred:

* Tailwind CSS v4
* shadcn/ui
* Framer Motion (light usage)
* Recharts
* Lightweight Charts
* Lucide Icons

## LAYOUT RULES

Always prioritize:

1. Information clarity
2. Market data visibility
3. Analysis readability
4. Fast scanning
5. Professional workflow

Avoid:

* oversized cards
* giant padding
* empty whitespace
* dashboard clutter
* unnecessary widgets

## CHART RULES

Charts are the most important element.

Requirements:

* large chart area
* zoom support
* pan support
* crosshair support
* timeframe switching
* responsive resizing

Preferred library:

* Lightweight Charts

## CARD SYSTEM

All cards should:

* use consistent spacing
* have consistent radius
* use subtle borders
* avoid excessive shadows

Avoid:

* glow effects
* neon overload
* distracting animations

## ANIMATION RULES

Use Framer Motion sparingly.

Allowed:

* hover states
* panel transitions
* loading states

Avoid:

* constant movement
* flashy animations
* decorative effects

## TYPOGRAPHY

Priorities:

* readability
* hierarchy
* accessibility

Use:

* clear headings
* compact data displays
* aligned metrics

Avoid:

* oversized text
* decorative fonts

## DASHBOARD PRINCIPLES

Every screen must answer:

1. What is happening?
2. Why is it happening?
3. What should the user do?

The interface should help users:

* understand markets
* understand risk
* understand sentiment
* understand confidence

NOT just show numbers.

## BEFORE ANY UI CHANGE

The agent must verify:

* Does this improve readability?
* Does this improve decision-making?
* Does this reduce clutter?
* Does this match Bloomberg/TradingView quality?

If not, do not implement it.
